# Satyam Yadav - Developer Portfolio

A responsive, single-page portfolio designed for GitHub Pages, Vercel, Netlify, or any static web host.

## Files
- `index.html` - portfolio content and structure
- `styles.css` - visual design and responsive layout
- `script.js` - small interactions (mobile navigation, reveal animations, current year)
- `assets/profile-placeholder.svg` - temporary profile image placeholder; replace with your photo later
- `assets/social-preview.svg` - social/share preview artwork, also ready for your photo update
- `assets/Satyam_Yadav_Resume.pdf` - resume copy linked from the site

## Publish on GitHub Pages
1. Create a GitHub repository (for example, `satyam-yadav-portfolio`).
2. Upload the files in this folder, keeping the `assets/` folder.
3. In GitHub: Settings -> Pages -> Deploy from branch -> `main` / root.
4. Add the resulting URL to LinkedIn's Contact Info and Featured section.

## Publish on Vercel
Import the repository into Vercel and use the default static site settings.

## Profile photo
Replace `assets/profile-placeholder.svg` with a square JPG/PNG and change the `<img src>` in `index.html` to the new filename. The design is already prepared for a professional headshot.
