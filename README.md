# Satyam Yadav — Developer Portfolio

A compact, animated, responsive portfolio for GitHub Pages / Vercel / Netlify.

## GitHub Pages structure

```text
satyam7475.github.io/
├── index.html
├── styles.css
├── script.js
└── assets/
    ├── Satyam_Yadav_Resume.pdf
    ├── satyam-profile.jpg
    └── social-preview.svg
```

## Publish on GitHub Pages

1. Use the public repository `satyam7475.github.io`.
2. Upload the files above and commit to `main`.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch → main → / (root)**.
5. Open `https://satyam7475.github.io`.

The site is static HTML/CSS/JS and needs no build step.
