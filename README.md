# Satyam Yadav — Developer Portfolio

Responsive personal portfolio built for GitHub Pages.

## GitHub Pages
Use the repository `satyam7475.github.io` and keep these files in the repository root:

- `index.html`
- `styles.css`
- `script.js`
- `satyam-profile.jpg`
- `Satyam_Yadav_Resume.pdf`
- `social-preview.svg`

Then enable **Settings → Pages → Deploy from a branch → main / root**.

## Notes
No framework or build step required. Upload the files directly and the site deploys as a static page.
